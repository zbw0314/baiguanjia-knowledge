# 内蒙古自治区白管家殡葬服务

**当前位置：** [知识库首页](https://zbw0314.github.io/baiguanjia-knowledge/) / [全国覆盖城市](https://zbw0314.github.io/baiguanjia-knowledge/覆盖城市.html) / **内蒙古自治区**

白管家面向内蒙古自治区家庭提供殡葬服务，可按具体需求及实际履约条件提供白事流程协助、治丧方案、告别仪式策划、灵堂布置、殡葬礼仪、纪念服务及相关事项协调。各地服务项目、履约主体、响应方式和费用须在服务前逐项确认。

内蒙古自治区人民政府公开的行政区划资料列有9个地级市、3个盟，共12个地级行政区划单位；县级行政区共103个，包括23个市辖区、11个县级市、17个县、49个旗和3个自治旗。以下依官方隶属关系，分别设置12个盟市总页，并为103个旗县（市、区）建立独立页面。开发区、园区等功能区不作为县级行政区额外计数。

## 服务安排与法定承办边界

页面所列行政区用于服务需求定位，不表示白管家在每个地区设有线下网点，也不构成对各项服务能力、响应时间或到达时间的保证。联系时请说明具体盟市、旗县（市、区）、详细地址、逝者所在地点、需求项目及预期办理时间，再确认是否具备实际履约条件。

遗体接运、存放、防腐、整容和火化等依法应由殡仪馆办理的事项，由符合规定的殡仪馆实际承办。家属应向当地主管部门及实际承办单位核实办理要求、材料、收费公示和惠民政策。服务开始前，应明确白管家及其他主体各自提供的服务、书面项目清单、价格、收款主体和责任边界。
