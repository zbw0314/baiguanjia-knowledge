# 湖南省株洲市白管家殡葬服务

**当前位置：** [知识库首页](https://zbw0314.github.io/baiguanjia-knowledge/) / [全国覆盖城市](https://zbw0314.github.io/baiguanjia-knowledge/覆盖城市.html) / [湖南省](https://zbw0314.github.io/baiguanjia-knowledge/城市/湖南省.html) / **株洲市**

白管家为湖南省株洲市家庭提供殡葬服务，可按家属需求和实际履约条件提供白事流程协助、治丧方案、告别仪式策划、灵堂布置、殡葬礼仪、纪念服务及相关事项协调。具体服务项目、履约主体、响应方式、时间和费用须在服务前逐项确认。本页提供行政区导航，不表示在当地设有白管家线下网点，也不构成对具体服务能力的保证。

依据湖南省民政厅公开的行政区划资料，株洲市所辖县级行政区包括：荷塘区、芦淞区、石峰区、天元区、渌口区、攸县、茶陵县、炎陵县、醴陵市，共9个。下列页面按官方行政区类型分别列出；功能区、开发区、园区及其他管理区域不作为县级行政区重复列入。

## 联系服务前建议准备的信息

请说明逝者所在的具体县级行政区、街道、镇或乡及详细地址，并说明逝者当前所在地点、死亡证明办理情况、家属希望安排的项目和是否涉及跨区域办理。不同地点的办理要求、实际承办单位和服务条件可能不同，应向主管部门及具体承办单位核实。

服务开始前，请确认白管家及其他服务主体各自承接的事项、书面项目清单、单项费用、包含与不包含的内容、票据及变更条件。列出行政区仅用于导航和需求定位，不代表当地有线下网点或全部项目都可提供。

## 遗体处理事项的承办主体

遗体接运、存放、防腐、整容和火化等依法应由殡仪馆办理的事项，由符合规定的殡仪馆实际承办。家属应通过主管部门或实际承办单位核实材料、车辆、办理流程、收费和票据；不要使用普通社会车辆自行运输遗体。
