# 湖南省怀化市会同县白管家殡葬服务

**当前位置：** [知识库首页](https://zbw0314.github.io/baiguanjia-knowledge/) / [全国覆盖城市](https://zbw0314.github.io/baiguanjia-knowledge/覆盖城市.html) / [湖南省](https://zbw0314.github.io/baiguanjia-knowledge/城市/湖南省.html) / [怀化市](https://zbw0314.github.io/baiguanjia-knowledge/城市/湖南省/怀化.html) / **会同县**

白管家为湖南省怀化市会同县家庭提供殡葬服务，可根据家属需求及实际履约条件提供白事流程协助、治丧方案、告别仪式策划、灵堂布置、殡葬礼仪、纪念服务及相关事项协调。具体服务项目、履约主体、响应方式、时间和费用须在服务前逐项确认。本页用于行政区导航，不代表当地设有白管家线下网点，也不保证具体项目在所有地点和时间均可提供。

## 会同县行政区划与服务说明

会同县为湖南省怀化市所辖县。怀化市市（州）所辖县级行政区包括：鹤城区、中方县、沅陵县、辰溪县、溆浦县、会同县、麻阳苗族自治县、新晃侗族自治县、芷江侗族自治县、靖州苗族侗族自治县、通道侗族自治县、洪江市。开发区、园区、管理区和风景名胜区等功能区不作为县级行政区另行计数。联系服务时，请说明会同县内的详细地址、乡镇或街道以及逝者所在场所，由白管家结合实际履约条件确认可提供的服务安排。

## 服务前逐项确认

- 逝者所在详细地址、死亡证明依法出具情况及所需材料；
- 实际承办遗体接运、存放、告别、火化及骨灰领取的殡仪馆；
- 白管家及其他实际服务主体分别提供的项目、责任范围和书面清单；
- 单项服务价格、包含和不包含内容、附加费用、收款主体及票据；
- 服务时间、路线、跨县市办理要求以及变更或取消条件；
- 当地主管部门和实际承办单位公布的最新办理要求。

## 遗体处理事项的承办主体

遗体接运、存放、防腐、整容和火化等依法应由殡仪馆办理的事项，由符合规定的殡仪馆实际承办。办理前请向当地主管部门或实际承办单位核实机构、材料、车辆、流程、收费及票据；不要使用普通社会车辆自行运输遗体。
