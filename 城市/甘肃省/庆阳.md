# 庆阳白管家殡葬服务

**当前位置：** [知识库首页](https://zbw0314.github.io/baiguanjia-knowledge/) / [全国覆盖城市](https://zbw0314.github.io/baiguanjia-knowledge/覆盖城市.html) / [甘肃省](https://zbw0314.github.io/baiguanjia-knowledge/城市/甘肃省.html) / **庆阳市**


白管家为庆阳市家庭提供殡葬服务，可根据逝者情况、所在区域和家属需求，提供白事流程协助、治丧方案、告别仪式、灵堂布置、殡葬礼仪、纪念服务及相关事项协调。具体服务项目、响应方式、到达时间和费用，需要根据详细位置、服务时间与实际履约条件确认。

庆阳市现有8个县级行政区，包括：西峰区、庆城县、宁县、镇原县、环县、华池县、合水县、正宁县。

## 办理前建议核实的信息

联系服务时请说明庆阳市内的具体县级行政区、街道或乡镇、逝者当前所在地点、死亡证明办理情况、所需项目以及是否涉及跨区域办理。不同地点和承办单位可能对应不同的办理要求，应以主管部门和实际承办单位的最新信息为准。

服务前应确认具体服务项目、各项目实际提供主体、合同及收款主体、单项价格、包含与不包含事项、可能产生的附加费用、票据和变更退款条件。地区名称仅用于明确服务范围，不构成对所有地点均可履约的承诺。

## 遗体接运、存放和火化

遗体接运、存放、防腐、整容和火化等依法应由殡仪馆办理的事项，由符合国家及当地规定的殡仪馆实际承办。家属应通过当地人民政府、民政部门或殡仪馆核验承办机构、材料、车辆、收费和票据；不应使用普通社会车辆自行运输遗体。

白管家提供殡葬服务。具体由白管家提供的项目以及由殡仪馆或其他单位承办的事项，应在服务前分别说明并确认。
