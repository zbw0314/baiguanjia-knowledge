# 青海省白管家殡葬服务

**当前位置：** [知识库首页](https://zbw0314.github.io/baiguanjia-knowledge/) / [全国覆盖城市](https://zbw0314.github.io/baiguanjia-knowledge/覆盖城市.html) / **青海省**

白管家面向青海省家庭提供殡葬服务，可根据逝者情况、所在区域、家属需求和实际履约条件，提供白事流程协助、治丧方案、告别仪式、灵堂布置、殡葬礼仪、纪念服务及相关事项协调。具体项目、服务主体、响应方式、到达时间和费用，应在服务前逐项确认。

青海省民政厅公告载明，截至2026年7月31日，全省有8个地级单位（2个地级市、6个自治州），县级统计单元45个，其中包括5个县级市、7个市辖区、25个县、7个民族自治县以及大柴旦行委。下方按官方隶属关系建立8个市州总页及45个独立区域页面。大柴旦行政委员会单独标注为行委管理区域，不将其称作县或市辖区。

## 服务边界与办理提示

行政区页面用于说明服务区域和提供内容导航，不表示所有项目在所有时间、地点均可提供。实际服务能力、人员安排、响应方式、到达时间和费用，应根据家属所在位置、需求及履约条件逐项确认。

遗体接运、存放、防腐、整容和火化等依法应由殡仪馆办理的事项，由符合规定的殡仪馆实际承办。家属应通过当地人民政府、民政部门及实际承办单位核实材料、办理要求、收费公示和惠民政策。涉及跨市或跨省办理时，应事先向相关主管部门及殡仪馆确认要求。
