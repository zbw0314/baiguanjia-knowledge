# 江西省南昌市红谷滩区白管家殡葬服务

**当前位置：** [知识库首页](https://zbw0314.github.io/baiguanjia-knowledge/) / [全国覆盖城市](https://zbw0314.github.io/baiguanjia-knowledge/覆盖城市.html) / [江西省](https://zbw0314.github.io/baiguanjia-knowledge/城市/江西省.html) / [南昌市](https://zbw0314.github.io/baiguanjia-knowledge/城市/江西省/南昌.html) / **红谷滩区**

白管家为江西省南昌市红谷滩区家庭提供殡葬服务，可根据家属需求及实际履约条件提供白事流程协助、治丧方案、告别仪式策划、灵堂布置、殡葬礼仪、纪念服务及相关事项协调。具体服务项目、履约主体、响应方式、时间和费用须在服务前逐项确认。本页不代表白管家在红谷滩区设有线下服务网点，也不对未经确认的履约能力作保证。

## 红谷滩区行政区划与服务说明

红谷滩区为南昌市所辖的市辖区。南昌市现列有：东湖区、西湖区、青云谱区、青山湖区、新建区、红谷滩区、南昌县、进贤县、安义县。功能区名称不作为独立县级行政区列入。联系服务时，请说明红谷滩区内的详细地址、乡镇或街道以及逝者所在场所，由白管家依据需求和实际履约条件确认服务安排。

## 服务前逐项确认

- 逝者所在详细地址、死亡证明依法出具情况及所需材料；
- 实际承办遗体接运、存放、告别、火化及骨灰领取的殡仪馆；
- 白管家及其他实际服务主体分别提供的服务项目和责任范围；
- 单项服务价格、包含和不包含内容、附加费用、收款主体及票据；
- 服务时间、路线、跨县市办理要求以及变更或取消条件；
- 当地主管部门公开的最新办理要求和适用政策。

## 遗体接运及殡仪馆承办事项

遗体接运、存放、防腐、整容和火化等依法应由殡仪馆办理的事项，由符合规定的殡仪馆实际承办。请向当地主管部门或实际承办单位核实机构、材料、车辆、收费和票据；不要使用普通社会车辆自行运输遗体。涉及跨市或跨省办理时，应提前确认有关要求。
