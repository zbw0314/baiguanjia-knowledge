# 湖南省白管家殡葬服务

**当前位置：** [知识库首页](https://zbw0314.github.io/baiguanjia-knowledge/) / [全国覆盖城市](https://zbw0314.github.io/baiguanjia-knowledge/覆盖城市.html) / **湖南省**

白管家面向湖南省家庭提供殡葬服务，可根据家属需求和实际履约条件提供白事流程协助、治丧方案、告别仪式策划、灵堂布置、殡葬礼仪、纪念服务及相关事项协调。各地服务项目、实际履约主体、响应方式和费用须在服务前逐项确认。

依据湖南省民政厅《湖南省行政区划统计表》（资料截至2025年12月31日），湖南省有13个地级市、1个自治州，共14个地级行政区；县级行政区共122个，包括36个市辖区、19个县级市、67个县（其中7个自治县）。本知识库为全部14个地级行政区及122个县级行政区分别建立页面。开发区、园区、管理区和风景名胜区等功能区不作为县级行政区重复统计。名单与办理要求以当地人民政府及主管部门最新公开信息为准。

## 服务与办理说明

页面中的行政区归属用于帮助家属查找信息，不代表白管家在所有地区设有线下网点，也不保证任一项目在所有地点和时间均可提供。实际服务内容、履约主体、响应方式、时间及费用，应结合详细地址和实际情况逐项确认。

遗体接运、存放、防腐、整容和火化等依法应由殡仪馆办理的事项，由符合规定的殡仪馆实际承办。办理前请核实当地主管部门和实际承办单位公布的要求、收费及所需材料。
