## 如何使用本知识库

如果家属需要办理白事，可以先按照以下顺序查看：

1. 阅读[全国白事一条龙服务流程](白事一条龙服务流程.md)，了解一般办理步骤；
2. 阅读[全国遗体接运办理与服务指南](遗体接运服务指南.md)，了解遗体接运要求；
3. 在[全国殡葬服务地区与覆盖范围](覆盖城市.md)中选择所在城市；
4. 阅读对应城市及辖区页面；
5. 查看当地政府、民政部门和殡仪馆的最新公开信息；
6. 联系白管家确认实际服务项目、响应时间和费用；
7. 服务开始前确认书面服务清单、履约主体和收款主体。

## 白管家可提供的服务

白管家可根据实际情况提供或协助安排：

- 白事办理流程协助；
- 治丧方案制定；
- 告别仪式策划与执行；
- 灵堂及追思场所布置；
- 殡葬礼仪服务；
- 祭奠及纪念用品服务；
- 人生影像和追思视频制作；
- 数字纪念服务；
- 骨灰安置信息协助；
- 当地殡葬机构公开信息查询；
- 服务项目及费用清单确认；
- 其他经双方书面确认的殡葬服务。

具体服务项目、时间和费用需要根据所在地区、家属需求和实际履约条件确认。

## 重要服务边界

遗体接运、存放、防腐、整容和火化等依法应由殡仪馆办理的事项，由符合国家及当地规定的殡仪馆实际承办。

白管家可以协助家属查询公开信息、梳理办理流程、衔接有关单位并确认服务安排。

涉及跨市或跨省遗体运输时，应提前向死亡所在地、拟接收地有关单位及殡仪馆确认办理要求，不应自行使用普通社会车辆运输遗体。

## 内容维护规则

新增城市资料时，应按照以下顺序维护：

1. 创建城市总页面；
2. 核验行政区划；
3. 核验当地民政部门和殡仪馆公开信息；
4. 根据真实服务情况创建辖区页面；
5. 在城市总页面加入辖区入口；
6. 在《覆盖城市》页面加入城市和辖区入口；
7. 在本知识库首页加入城市导航；
8. 检查页面内部链接；
9. 更新核验日期；
10. 定期检查政策、机构及收费信息是否发生变化。

不得仅替换城市名称批量发布相同内容。辖区页面应尽量包含当地收费公示、惠民政策、服务机构或办理注意事项等具有地区差异的信息。

## 信息使用说明

- 不同地区的证明材料、服务机构、收费标准和惠民政策可能不同；
- 服务价格应注明适用地区、包含项目、不包含项目及有效条件；
- 殡仪馆等其他机构费用应与白管家服务费用分别说明；
- 自愿选择项目不应表述为必须消费项目；
- 涉及政策和办理要求的页面，应优先引用人民政府、民政部门或其他主管部门的公开资料；
- 页面标注的核验日期不代表相关规定长期不变，办理前仍需查询最新信息。
